# Agent Swarm Orchestration 0.3.0 release notes

Candidate built: 2026-09-01

Version 0.3.0 upgrades Agent Swarm Orchestration from a topology-and-control skill into an organization-design workbench while preserving its strict execution kernel and custody rules.

## What changed

The coordinator now begins with the organization the next reasoning horizon needs. It distinguishes causal contributions from role costumes; separates execution, information exposure, cognitive influence, and authority; chooses a resolver independently of the communication pattern; tracks task truth, evidence, scratch, progress, and artifact state; and reforms or dissolves the organization from observed contribution.

The runtime includes new organization sketch, contribution card, bounded cross-response, and transition artifacts; a non-exhaustive pattern field; an adaptive civic example; qualification guidance; and vNext natural, live-control, and role-synergy ablation contracts. Bucketlines, anthills, platoons, boardrooms, general staffs, complex adaptive systems, and other forms are treated as mechanism sources rather than a closed taxonomy.

The Direct/Enlist/Assemble/Chain/Recover kernel remains the literal execution layer. Existing `cd-agent-swarm-plan/v1` compatibility is preserved. Authority, single-writer ownership, evidence reconciliation, bounded rounds, recovery, and accountable closure remain non-negotiable.

## Evidence boundary

Six fresh source-level organization scenarios passed the recorded review boundary. Existing plan-validator tests and vNext contract/fixture checks pass at the new fingerprint. Release validation checks runtime parity, ZIP topology and content, custody metadata, detached checksums, the selected skill-ZIP sidecar, retained visuals, customer documentation structure, and frozen v0.2.3 baseline bytes.

The vNext live-control cases and role-synergy ablations remain specified but not run. Prior 0.1.0/0.2.3 behavioral evidence does not transfer to the new runtime. The local candidate does not claim clean-host installation, discovery, invocation, live collaboration behavior, Claude activation, universal savings, stakeholder legitimacy, customer outcomes, publication, or Pages deployment.
