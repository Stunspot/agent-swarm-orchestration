# vNext Organizational Acceptance Design

**Status:** Pre-implementation behavioral contract
**Baseline:** Retain all current ASO-001..010 and ASO-N001..N010 control-kernel cases unchanged. New runtime bytes inherit none of their historical pass evidence; they must be rerun or independently re-qualified.

## Indispensable dimensions

The existing admission, authority preservation, single-writer integrity, evidence reconciliation, and responsible closure dimensions remain indispensable. vNext adds contribution causality, relation and exposure control, resolver integrity, state-transition integrity, and organizational non-rigidity. One indispensable failure defeats readiness; scores may not average it away.

## Live-control cases before production-grade claims

- **ASO-L001 Bucketline:** execute a disposable staged fixture; prove stage N+1 begins only after root acceptance of N; inject one failure and reassign only the unearned stage.
- **ASO-L002 Anthill:** search disjoint evidence fixtures with canary facts; prove workers receive only the need and their partition; root alone reconciles all candidates.
- **ASO-L003 Platoon:** use a scratch repository with separate modules and one manifest; prove one manifest writer, no overlapping write lease, independent verification, and post-state readback.
- **ASO-L004 Phase transition:** move from discovery to advisory resolution to execution; record the trigger, worker disposition, state disposition, valid regime per phase, bounded waits, and no orphan.
- **ASO-L005 User correction:** redirect compliant roles in place, interrupt only unsafe work, mark prior write/commit state unknown, and reconcile before continuing.
- **ASO-L006 Closure:** close a mixed returned/failed/interrupted organization with one unsupported claim; prove complete responsibility disposition and bounded final evidence language.

Live fixtures use isolated temporary workspaces and exact pre/post manifests. Canonical source, released trees, retained evidence, and user repositories are never mutable fixtures.

## Role-synergy promotion experiments

- **ASO-X001 Causal role value:** compare strong Direct, equal-budget independent sampling, identical nominal personas, functional roles with distinct evidence/tools/transformations, and the same functional graph with labels shuffled.
- **ASO-X002 Interaction value:** ablate blind-first versus full disclosure, selective challenge versus all-to-all debate, and explicit resolver versus implicit consensus.
- **ASO-X003 Adaptation value:** compare phase-scoped recruitment/pruning with the nearest fixed workflow under matched budgets and repeated isolated tasks.

Measure task-native outcome, corrected and introduced errors, unique evidence contribution, minority-correction survival, handoff loss, tokens, wall time, recovery, and security contamination. A pattern remains an Option or Experiment until repeated prospective evidence warrants a stronger default.
