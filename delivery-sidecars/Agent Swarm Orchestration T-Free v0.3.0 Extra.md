# Description

Designs a temporary agent organization around the work: distinct contributions, controlled information sharing, shared-file ownership, bounded interaction, and one accountable integrated result. It can use direct work, one helper, parallel slices, sequential stages, or recovery, then adapt or dissolve the organization as its contributions change.

The orchestration layer is designed to prevent duplicated research, conflicting edits, lost evidence, and unreconciled worker reports. One root agent remains responsible for the final answer.

# Usage Notes

Copy the .zip from "Additional Files" to your chosen harness or Chat project. Attach or reference it in chat and say, "Install this Augment." The installation prompt is optional.

- Use when a distinct contribution, independent review, parallel slice, or sequential stage can improve the result. Simple work can stay with one agent.
- Tell it the finished outcome you need, what evidence will count, any shared files, and the parts that must not be changed.
- Requires a harness that can create and coordinate subagents. It does not give those agents permission to use credentials, take destructive actions, or exceed your authority.

Public GitHub Repo: [agent-swarm-orchestration](https://github.com/Stunspot/agent-swarm-orchestration)
